# Jukebox Saloon

A lightweight web-based audio player built for the Dustline saloon trial on Pixl.
[Live Demo](https://saloonjukebox-ruby.vercel.app/)


## Description

Jukebox Saloon provides an interactive, western-themed music experience directly in the browser. Designed with simplicity and performance in mind, the application features an automatic queue system and standard playback controls, allowing users to listen to themed audio streams seamlessly without additional dependencies.

## Getting Started

### Dependencies

* Any modern web browser (Google Chrome, Mozilla Firefox, Safari, Edge)
* No additional packages or server environments required.

### Installing

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/travletothefurureprogramming/Saloon-Jukebox.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Saloon-Jukebox
   ```

### Executing program

1. Open the `index.html` file in your preferred web browser:
   * **Linux/macOS:**
     ```bash
     open index.html
     ```
   * **Windows:**
     ```cmd
     start index.html
     ```
   * Or simply double-click `index.html` in your file explorer.

## Features

* **Western Track List:** Pre-configured playlist matching the saloon aesthetic.
* **Continuous Playback:** Automated queue handling for smooth uninterrupted listening.
* **Audio Controls:** Full control over audio state including play, pause, skip, and volume adjustment.
* **Modern Interface:** Responsive UI built with Tailwind CSS.

## Tech Stack

* HTML5
* Vanilla JavaScript (ES6+)
* Tailwind CSS

## Help

If audio fails to play automatically on page load:
* Most modern browsers block autoplay with sound. Click anywhere on the interface or interact with the **Play** button to initiate playback.
